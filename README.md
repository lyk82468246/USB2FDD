# USB2FDD

USB2FDD is an AI8051U/C251 firmware project for building a USB-to-floppy-disk-drive controller. The project is generated by STC AICUBE and keeps hand-written code inside `AICUBE_USER_*` regions so the project can be regenerated safely.

## Current Status

- MCU: STC AI8051U, C251 toolchain
- USB mode: USB CDC command channel
- FDD target: standard 34-pin PC floppy drive interface
- Implemented:
  - Safe FDD output idle state
  - Motor, drive select, direction, step, side, density control
  - Track 0 homing and simple software track seek
  - `INDEX#` counting, period measurement, and RPM estimate
  - `RDATA#` flux interval capture into an xdata ring buffer
  - One-revolution capture bounded by `INDEX#`

## AICUBE Rules

Peripheral selection, pin mapping, pull mode, high-Z mode, Schmitt trigger, and other physical pin settings are configured in AICUBE.

Hand-written code must only be placed between generated markers:

```c
//<<AICUBE_USER_XXX_BEGIN>>
//<<AICUBE_USER_XXX_END>>
```

FDD code must use signal aliases from `Sources/inc/config.h`, not physical port names in application logic.

## FDD Signal Aliases

Current aliases are generated by AICUBE in `Sources/inc/config.h`:

- `DSKCHG`
- `WPT`
- `RDATA`
- `FDD_INDEX`
- `TRK0`
- `DENSEL`
- `WDATA`
- `WGATE`

## USB CDC Commands

Text commands are case-insensitive.

```text
PING
SAFE
STATUS
MOTOR 0|1
SELECT 0|1
DIR 0|1
STEP
HOME
SEEK n
SIDE 0|1
DENSEL 0|1
INDEX_RESET
INDEX_WAIT
RPM
FLUX_RESET
FLUX_START
FLUX_STOP
CAPTURE_REV
FLUX_READ
```

`FLUX_READ` returns a binary packet:

- Byte 0: ASCII `F`
- Byte 1: sample count
- Remaining bytes: little-endian `uint16_t` timer intervals

## Suggested Bring-Up Flow

```text
SAFE
MOTOR 1
SELECT 1
INDEX_WAIT
RPM
HOME
SEEK 10
CAPTURE_REV
STATUS
FLUX_READ
```

For a 300 RPM drive, `RPM` should be close to `300`, and the index period should be close to `200 ms`.
